# MaligPx Live Validation

Minimal clinical/research interface for the accepted MaligPx Steele live validation.

The scientific computation is unchanged from the validated web bundle. The app retains the frozen-input SHA-256 check, seed control, frozen-seed regression check, conditional human-readable interpretation, figures, patient explorer, patient-level table, CSV/JSON downloads, and method/seed/Steele explanations.

Deploy `app.py` with Python 3.12.
